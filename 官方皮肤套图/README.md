# 官方皮肤套图

从官方皮肤总览图抠取的单角色 PNG 套图。**当前只有 28 张（占 56 个角色的 50%）**，剩 28 个角色官方没出皮肤，需要外部素材补齐。

---

## 目录结构

```
官方皮肤套图/
├── 原图/
│   └── 官方皮肤总览_780x1044.jpg    # 唯一权威来源，禁止替换/重命名
├── goose/                # 鹅阵营 PNG（目标 24 张，现有 14）
├── duck/                 # 鸭阵营 PNG（目标 23 张，现有 10）
├── neutral/              # 中立阵营 PNG（目标 9 张，现有 4）
├── 裁切坐标表.md          # 每个角色的 bbox，抠图/脚本裁切用
├── 裁切坐标表.json        # 同上，机器可读
└── 皮肤覆盖情况.md        # 已有 / 缺失清单 + 找素材建议
```

## 命名规范（硬性）

与 `official_camps_v3/` 完全对齐，便于后续直接替换 logoSet：

- 文件名：`<阵营前缀>_<角色名>.png`，如 `goose_警长.png`
- 角色名用 `config/roles.json` 里的 `name` 字段（短名），**不用** `officialName`
  - 例：官方叫「正义使者」→ 文件名写 `goose_正义使者.png`（与 config 一致）
  - 例：官方叫「爆炸王」→ 文件名写 `duck_炸弹.png`（config 的 name 是「炸弹」）
- 透明背景 PNG，**禁止有损压缩**（WebP q82 之类会把透明边缘搞出毛边）
- 建议 240×240 画布居中，跟 `official_camps_v3` 一致

##抠图工作流

1. 把 `原图/官方皮肤总览_780x1044.jpg` 喂给 AI 抠图工具
2. 附上 `裁切坐标表.md` 里的 bbox，让工具按坐标裁，不要自己猜位置
3. 明确要求：**只保留角色本体，去掉下方中文标签，输出透明背景 PNG**
4. 落盘到对应阵营子目录，文件名严格按命名规范
5. 抠完在项目根开一个临时预览 HTML 目视复核，**不要**起本地 http 服务、不要内嵌有损缩略图

## 注意

- 这套皮肤是**装扮（Outfit）**，不是角色形象。同一个装扮在任何角色身上都能穿，所以「28 个角色有皮肤」本质是「作者给这 28 个角色各配了一套装扮」，不是官方为该角色专属绘制的形象。
- 因此缺失的 28 个角色**理论上不存在同套皮肤**。要补齐只有两条路：找同作者的其他皮肤图/ 接受风格不统一地混用 `official_camps_v3` 的官方本体图。详见 `皮肤覆盖情况.md`。
