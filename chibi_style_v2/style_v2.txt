# 鹅鸭杀角色Logo生成基础规范 (style_v2.txt)

> 【V2 修订说明】相对 V1（style.txt）的唯一变化：背景策略从“透明背景”改为“纯白背景”。
> 原因：当前生图模型无法输出真透明通道，强求透明只会产出假棋盘格废图；V2 改为出均匀纯白底图，后期再沿闭合描边抠图转透明 PNG。
> 版权与设计规范（第一~六节）与 V1 完全一致，未做改动。

## 〇、V2 背景策略（抠图友好三要点）
1. **均匀纯白**：整张背景必须是同一种纯白（#FFFFFF），无渐变、无噪点、无纹理——底色越均匀，后期一键抠图越干净。
2. **零接触**：主体任何部位不得触碰画布四边，与边缘保持安全留白，防止抠图时裁边或带入背景杂边。
3. **描边闭合**：主体外轮廓必须有完整闭合的深色粗描边（尤其白色/浅色的鹅类身体部位），确保浅色主体与纯白背景之间始终有清晰的深色分界，抠图沿描边走不会误伤主体。

## 一、核心原则：版权安全 与 用户识别 双达标
本规范有两个底线目标，缺一不可：
1. **版权安全**：所有产出必须是原创重绘，严禁照抄、描摹官方贴图的造型、纹样、构图与细节。
2. **用户识别**：用户不看文字标注，也能一眼认出图上是谁。为避嫌改得面目全非导致认不出角色，与照抄官方同属不合格。

设计总纲——**借“魂”不抄“皮”**：
- **可借（身份概念层）**：角色主色调、标志性身份符号的“概念”（如警长=警徽、刺客=准星、呆呆鸟=扁嘴）、阵营气质。这些是玩家认角色的通用依据，属于概念层面。
- **必改（具体表达层）**：符号的具体纹样与几何造型、五官画法、身体比例、装饰细节、构图姿势，全部自行设计。这些是官方美术的具体创作表达，直接照搬即构成侵权风险。

拿不准的元素宁可改得更远，但以“用户还能认出角色”为下限。

## 二、平衡点对照表（设计每个角色时逐条自查）
| 设计要素 | 怎么借（保住识别度） | 怎么改（避开版权风险） |
|---|---|---|
| 主色调 | 保留角色主色方向（警长金、刺客暗红、呆呆鸟橙红扁嘴等） | 具体色值、明暗、饱和度自行调配，不直接从官方图取色 |
| 身份符号 | 保留符号“是什么”：警徽、准星、刀、巫毒娃娃等概念不变 | 重新设计符号“长什么样”，不复制官方徽记的纹样细节 |
| 剪影轮廓 | 大致气质呼应官方（圆胖/瘦长/戴兜帽等第一印象） | 改为 Q 版比例（如二头身、大头小身），与官方身形明显区分 |
| 标志道具 | 官方用什么道具表达身份，产出沿用同一道具概念 | 道具的造型、角度、质感全部原创 |
| 取景形式 | 官方 logo 是完整角色、头部/肩部以上特写还是纯图标，产出沿用同一形式（详见第六节） | 具体姿势、朝向、纹样仍全部原创，只贴合取景范围，不复刻构图细节 |

**双重验收（两条都过才算合格）**：
1. **识别检验**：遮住角色名，单看图能否说出“这是警长/刺客/呆呆鸟”？说不出 → 提高主色与符号的辨识权重。
2. **原创检验**：与官方图并排摆放，第一眼是否像“同一张图微调换色”？像 → 加大 Q 版化与造型改造力度。

**三条红线**：
- 禁止照搬官方贴图的五官、纹样、构图。
- 禁止为避嫌过度抽象化，导致用户认不出角色。
- 禁止把官方独有的多个特征原样叠加组合（单一符号概念可借，官方专属特征组合不可抄）。

## 三、用户体验硬指标
1. **小图可读性**（九宫格/列表展示场景）：
   - 近黑占比 ≤40%，防止小图下糊成黑块。
   - 每图至少含一块 ≥8% 面积的高饱和亮色，保证小图第一眼聚焦。
2. **零文字依赖**：角色身份只靠“主色 + 符号 + 剪影”三要素传达（与第七节“严禁文字”呼应）。
3. **成套一致性**：全部角色共用同一套线条粗细、上色方式、头身比例，用户混排使用不违和。
4. **小尺寸场景契合**：构图饱满居中、边缘干净，适配头像、卡片、记牌器图标等小尺寸展示。

## 四、统一视觉风格基调
- 画面类型：极简可爱 Q 版卡通插画，精品潮玩贴纸质感。
- 构图比例：1:1 方形构图，主体饱满居中，占画面约 80%~90%，四周留少量安全边距（V2：边距内必须为均匀纯白，主体不触碰画布边缘，便于后期抠图）。
- 线条质感：厚实干净的黑色粗描边勾线，线条圆滑流畅，形体以圆润、钝角化为主。
- 上色光影：干净的平涂上色，局部点缀弧形亮光，无复杂写实渐变。
- 厚描边 + 平涂本身即与官方画风形成区隔，是原创性的第一道保险，不可削弱；同时闭合的深色描边也是白底抠图的分界依据，必须完整闭合。

## 五、各阵营神态方向（仅提供宏观氛围基调，具体表现自由发挥）
- 好人阵营（鹅）：整体偏向正面、呆萌、元气、无辜或认真憨态，保持纯良可爱的基调。
- 坏人阵营（鸭）：整体偏向狡黠、心机、反差萌、恶作剧得逞，透着滑稽幽默的小邪恶。
- 中立阵营：整体偏向荒诞、疯批、神秘、自我或置身事外的看戏感，体现各自为政的独特怪咖感。

## 六、取景形式贴合官方素材（硬性规则）
写每个角色的 prompt 前，必须先查看官方参考图（official_camps_v3 中该角色原图），确认官方 logo 的取景形式，产出严格沿用同一形式——整体上贴合官方素材的呈现方式：

| 官方取景形式 | 产出要求 | Prompt 写法要点 |
|---|---|---|
| 纯图标/物件（非角色形象，如刀、徽章、炸弹等） | 同样是图标，以该物件为独立主体 | 直接以物件为主体描写，用统一 Q 版质感演绎，不擅自改成角色形象 |
| 完整角色（一整只鹅/鸭/完整形象，头身四肢齐全） | 同样是完整角色 | 写明“完整全身形象”，列出身体组成部分（头部、身体、翅膀/四肢等），防止模型截断成局部 |
| 仅头部 | 同样仅头部特写 | 写明“仅头部特写，不含任何身体部分”，防止模型自行补全身体 |
| 肩部以上 | 同样肩部以上半身特写 | 写明“肩部以上半身特写，不含下半身” |

执行要点：
- 取景形式跟官方走，不许自行升级或降级：官方全身 → 不许只给头像；官方头像/半身 → 不许扩成全身；官方图标 → 不许改成角色。
- 为什么贴合：取景形式本身就是玩家识别角色的一部分（玩家对“某角色是全身呈现、某角色是头像呈现”有既定预期），属于第一节的“身份概念层”，可借。
- 与“必改构图”不冲突：必改的是具体姿势、朝向、角度、纹样等创作表达；本条贴合的只是取景范围这一呈现形式，不涉及构图细节的复制。
- 拿不准就翻官方实图核对，不要凭记忆或凭其他角色的形式类推。

## 七、输出硬性技术约束（必须严格执行）【V2 改写】
- 背景必须为均匀纯白（#FFFFFF）：
  - 整张背景为同一种纯白颜色，无任何渐变底色、环境色、噪点、纹理。
  - 【核心负向规避】：严禁绘制任何“灰白相间的棋盘格”“伪透明马赛克网格”“假透明占位格”。（V1 曾强求真透明通道，模型做不到只会产出棋盘格废图，V2 一律改为纯白底 + 后期抠图。）
  - 严禁任何投影、地面阴影、倒影、光晕、发光边缘——主体与背景之间不允许存在任何过渡色。
- 主体必须在取景范围内完整居中，不裁切、不穿模、不触碰画布四边（“完整”指取景形式内的主体完整，如头部特写即头部本身完整呈现；取景形式按第六节贴合官方）。
- 主体外轮廓深色描边必须闭合完整、粗细均匀，白色/浅色身体部位与背景之间不允许出现描边断口。
- 严禁出现任何文字、英文字母、水印、边框。

## 八、提示词纯白背景标准约束尾缀（写任务 Prompt 时直接调用）【V2 改写】
编写生图 prompt 时，末尾统一强制使用以下标准闭环语句，以封杀渐变底、投影与棋盘格：
> “整图为纯白色纯色背景：背景为均匀纯白（#FFFFFF），严禁任何渐变、阴影、投影、光晕或棋盘格；主体外轮廓为完整闭合的深色描边，与白色背景分界清晰，不触碰画面边缘；”

## 九、Prompt 组装速查（写批量任务时按此拼接）【V2 微调】
第一步：翻官方参考图（official_camps_v3 该角色原图），确认该角色的取景形式（图标 / 完整角色 / 头部特写 / 肩部以上）。
识别要素：主色方向 + 标志符号（写“概念”，具体造型自行发挥）+ Q 版轮廓 + 官方同款取景形式 →
体验要素：近黑 ≤40% + ≥8% 高饱和亮色 + 居中饱满 + 不触边 →
收尾：第八节纯白背景标准尾缀。
出图后处理：白底图沿闭合描边抠图转透明 PNG 后再投入使用；抠图成品仍遵守项目红线“透明 PNG 禁止有损压缩”。
