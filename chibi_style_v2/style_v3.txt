# 鹅鸭杀角色 Logo 生成规范 (style_v3.txt)

## 一、核心设计原则（版权安全 与 角色识别）
1. **借概念保识别（绝对底线）**：
   - 继承官方角色的**核心身份符号概念**、**主色调方向**与**阵营气质**。
   - 目标：玩家不看任何文字标注，**一眼就能秒认出图上是哪个角色**。
2. **改表达避侵权（原创手段）**：
   - 严禁描摹、描边官方原图的具体线条、写实纹样与构图。
   - 角色统一重绘为原创 **Q 版大头小身（二头身）**形体，形体饱满、钝角倒角化。
   - 采用**全封闭粗黑描边 + 纯色块平涂（Cel-shading）**风格，从底层画风上与官方细腻写实插画形成绝对的版权区隔。
3. 版权安全区隔法则（严禁 1:1 元素堆叠）
    - **角度差异化**：严禁所有角色都采用呆板的“正面对称大头照”，鼓励采用 **微侧视 30 度（3/4 侧脸）** 或 **萌系微歪头**，从构图上切断与原版的完全重合。
    - **打破绝对对称**：
    - 若官方五官有特殊特征（如旋涡眼），可采用“单侧突出特征 + 另一侧做表情互动（如半眯挑眉/单眼wink）”。
    - 帽子与核心饰品尽量**偏心斜戴、侧向摆放**，避免与原版位置分毫不差。
    - **神态萌化反差**：将原版的写实/阴暗感，转化为“潮玩盲盒贴纸”的圆润反差萌，只借其“身份概念”，不抄其“构图骨架”。

## 二、通用角色视觉 DNA 提取法则（四位一体锁定）
在为**任意角色**编写生图提示词前，**严禁根据角色的文字名称去脑补现实世界的职业道具**（如：叫巫医就脑补采药葫芦、叫医生就脑补听诊器），必须先对官方参考图执行以下“四位一体”解构，并在 Prompt 中严格对齐：

| 视觉锚点层级 | 规则定义（强继承） | 转化与原创执行标准 |
| :--- | :--- | :--- |
| **1. 头部标志装束** | **同品类头部物件强继承** | • 官方戴什么品类的帽子/发饰，Prompt **必须且只能**写同品类（如：高顶礼帽+骷髅、牛仔帽、侦探帽、无帽光头等）。严禁擅自更换为头巾、花环等其他头饰。<br>• 原创手段：将帽子几何外形 Q 版化、圆角化重绘。 |
| **2. 五官异质特征** | **特殊眼睛/面部强保留** | • 观察官方五官是否有**特殊视觉符号**（如：旋涡催眠眼、十字准星眼、红心眼、刀疤、独眼罩、墨镜、不对称大小眼等）。<br>• **红线**：若官方有特殊眼部特征，**严禁**降级抹杀为普通的“眯眯眼”或“黑豆眼”，必须保留该特殊概念。 |
| **3. 颈胸核心服饰** | **上半身剪影结构强继承** | • 官方颈部与胸口的核心特征（如：锯齿羽毛领、警徽、领结、高领风衣、斗篷、围巾）必须体现，这是角色识别的第二大轮廓。<br>• 原创手段：简化写实布料褶皱，以简约平涂色块与粗线条呈现。 |
| **4. 持物状态法则** | **双手交互状态强对齐** | • **【官方无持物】**：若官方角色双手未持有道具，Prompt **绝对严禁自行添加任何手持道具**（严禁强行捧葫芦、抱布偶、举药罐）。<br>• **【官方有持物】**：仅当官方素材明确持有核心专属道具（如刀、放大镜、炸弹）时方可描写，且道具需圆润 Q 版化。 |

## 三、四类取景范围（严格贴合官方素材，不许擅自升降级）
写词前必须对照官方参考图，锁定对应的取景形式：
| 官方类型 | 产出形态要求 | 提示词关键形态约束词 |
| :--- | :--- | :--- |
| **纯图标/道具** | 独立物件/道具为主体，不画角色 | 单个独立物件/道具徽标，无角色形象，45度角/正视角居中 |
| **完整角色** | 全身立绘（头、躯干、四肢齐全） | Q版二头身完整全身立绘，大头圆身，完整四肢/翅膀与脚蹼 |
| **仅头部** | 纯头部大特写，不画脖子与身体 | 纯头部大特写徽章构图，不含任何颈部与身体部位 |
| **肩部以上** | 半身特写，胸部以上露出肩线 | 肩部以上半身特写徽章构图，露出领口与双肩，不画下半身 |

## 四、画面规格与视觉硬指标
1. **构图比例**：1:1 正方形；主体饱满居中，占比 **80%~90%**；四周留有充足安全白边，**主体任何部位绝不触碰画布边缘**。
2. **画风质感**：2D 极简 Q 版矢量潮玩贴纸风；形体以圆润、钝角倒角化为主。
3. **轮廓线条**：外轮廓必须有**厚实、平滑、全封闭的深色/纯黑粗描边**（浅色/白色部位与背景之间绝不允许断线，保障后期一键抠图）。
4. **色彩工艺**：纯净平涂上色（Cel-shading），局部点缀极简月牙形小弧光；严禁写实渐变与噪点。
5. **小图可读性**：画面近暗色占比 **≤40%**，必须包含至少一块面积 **≥8% 的高饱和亮色**点缀作为视觉中心。

## 五、阵营神态基调（结合五官异质性）
*注意：在保留“第二节·五官异质特征”的前提下，融入阵营情绪，严禁所有人千篇一律眯眼笑：*
- **好人阵营（鹅）**：纯良、呆萌、元气、憨态认真（圆豆豆眼/正义注视，嘴喙平稳）。
- **坏人阵营（鸭）**：狡黠、心机、反差萌、幽默小邪恶（锐利眼/挑眉/特殊眼，嘴角单侧微翘坏笑）。
- **中立阵营**：荒诞、疯批、怪咖、置身事外的放空感（放空呆滞眼/斗鸡眼/特殊眼，夸张大嘴喙）。

## 六、技术红线与负向清单（绝对禁止）
1. **背景绝对纯白**：整图背景为统一纯白（`#FFFFFF`），严禁任何渐变底色、环境色、地面阴影、投影、光晕。
2. **严禁棋盘格**：严禁生成任何灰白相间的“假透明网格/马赛克占位格”。
3. **严禁“望文生义自由发散”**：严禁脱离官方美术，根据文字字面含义强加民俗、职业多余道具。
4. **严禁“千人一面双手捧物”**：原版无持物的角色，严禁画成双手在胸前抱物摆拍。
5. **零杂质**：主体不裁切、不穿模；画面严禁任何文字、英文字母、符号水印、图框边缘。
